# 秋招投递助手 · 2027届

一个本地静态的秋招投递管理网站，聚合飞书多维表格 + 腾讯文档智能表格的校招岗位信息，合并去重后提供多维筛选、投递级别标注、投递状态跟踪。

## 功能

- **三源数据合并去重**：飞书多维表格（主数据）+ 两份腾讯文档智能表格
- **智能标注**：✅ 已投递 / ⭐ S·A·B 投递级别 / 🕐 公告时间（7天内标 NEW）
- **个人标记**：⭐ 收藏 · 🚫 不合适 · ✅ 已投递（互斥联动，localStorage 持久化）
- **多维筛选**：投递状态 / 收藏 / 不合适 / 级别 / 企业性质 / 招聘类型 / 学历 / 笔试 / 行业 / 地点
- **排序**：最新公告优先（默认）/ 级别优先 / 已投递优先 / 公司名
- **位置记忆**：刷新后自动恢复筛选条件、页码、滚动位置

## 本地运行

```bash
cd 本项目目录
python3 -m http.server 8777
# 打开 http://localhost:8777
```

> 数据文件 `data.json` / `meta.json` 为静态数据快照，由抓取脚本生成。

## 数据结构

- `index.html` — 单文件前端应用
- `data.json` — 岗位数据（合并去重、过滤后的结果）
- `meta.json` — 筛选维度统计元数据
